Before you start

Everything on the staging site is test data: the people, cars and phone numbers are made up, and payments run in Razorpay test mode, so no real money moves. Please don't enter real customer details.

You will need a phone (Android with Chrome, or iPhone with Safari) for the resident and cleaner tests, and a laptop for the admin tests. Some tests are done on a second day, because a wash can only be recorded on its scheduled day; they're marked Day 2.

To switch roles, sign out (top right) and sign in with another account. On one device, use a private or incognito window for the second role.

Known items in this build

These are already logged. You don't need to report them.

  1. Payment captions. After a payment, the result title still reads "Payment successful (simulated)". The invoice page and admin dashboard also mention simulated payments. The payments themselves are real Razorpay test-mode transactions. The screens are frozen, so these captions change only with your written approval.
  2. Retaking a photo. If a cleaner retakes a photo, they should wait until the new size ("Compressed: … KB") appears before tapping Confirm. Tapping too early saves the previous photo. The fix is also waiting for your approval.
  3. Vehicle reference photo. The job screen shows "Photo unavailable" where a reference photo of the car would appear; reference photos aren't stored in this version.
  4. "Earlier months" summaries in the resident gallery stay empty until the monthly roll-up feature is added. All detailed history is shown.
  5. Accounts. New cleaner and admin accounts, and password resets, are done by Vernex support on request. There's no in-app screen for them in this version.
